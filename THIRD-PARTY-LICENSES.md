## Notes

- The base image and guest keypair are **generated per site** by the
  pinned syzkaller tree's `tools/create-image.sh` (Apache-2.0 script, per
  its header) via `tools/make-base-image.sh`; provenance recipe in
  `bundle/README-HANDOFF.md` 'Base image provenance'. The base embeds its
  own pubkey, so the generated keypair stays paired with the base. The
  pair bundled until 2026-09-26 (rotation) is no longer distributed.
- **Guest SSH keypair** (`bookworm.id_rsa`, generated per site): a
  disposable syzkaller-`create-image.sh`-style credential. It grants
  passwordless root SSH **only** to QEMU guests built from your generated
  base image on your private network. It is not a credential for any other
  service. Treat it as throwaway: regenerate the pair (with the base) and
  re-bake the image before any non-sandboxed deployment. The pair bundled
  until 2026-09-26 (fingerprint `SHA256:hp4uezultsFtRDrHSnagtgclnK3E9QI144ZlpPuS+wg`)
  is retired and no longer distributed.
- **NFSv4 XDR** (`tools/nfs-proxy/schema/nfs4/`): each RFC 7531/5662/7863 says
  "Code Components extracted from this document must include Simplified BSD
  License text"; the extracted files keep that text verbatim at their head, and
  `SOURCES` pins every RFC text and extracted file by SHA-256. RFC 5531 (2009)
  carries no such Code Components statement. `prelude.x` reproduces two of its
  protocol definitions verbatim (the five `auth_flavor` constants and the
  five-member `authsys_parms`) only because the NFSv4 XDR names them without
  declaring them; RFC 5531 remains under BCP 78 and the IETF Trust Legal
  Provisions. The repository owner accepted this use (2026-10-13, PR #27).
- RFC 9754's own extraction script yields XDR without the license text, so
  `rfc9754.x` (kept byte for byte as the RFC prints it, to match its pin) has
  none. Its Code Components are under the same IETF Trust Revised BSD
  License, whose text heads `rfc8276.x`.
- `rfc8435-layouttype4.x` and `rfc8154-layouttype4.x` each hold one
  definition (`enum layouttype4`) that RFC 8435 and RFC 8154 state in their
  prose, copied by rule from the pinned text. Both RFCs say their Code
  Components carry the Simplified BSD License text; it is the text at the
  head of `rfc8276.x`, which each file's header names.
- Binaries built from the bundled sources (kernel `bzImage`, syzkaller
  binaries) inherit the licenses of their sources as above.
- The kernel and syzkaller patch series must be distributed under their
  upstream licenses; do not relicense them.
